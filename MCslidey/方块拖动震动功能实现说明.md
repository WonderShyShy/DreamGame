# MCslidey 方块震动反馈系统实现说明

## 📋 功能概述

本次更新为MCslidey游戏添加了全面的震动反馈系统，基于Nice Vibrations v4.1.2插件实现。震动功能包含**拖动震动**和**消除震动**两大类，为玩家提供丰富的触觉反馈体验。

## 🎯 震动触发场景

### 拖动震动系统

#### 1. 格子吸附震动 (Grid Snap Vibration)
- **触发条件**: 慢速拖动时，方块自动吸附到格子中心
- **震动类型**: `HapticPatterns.PresetType.Selection`
- **特点**: 轻微的选择确认震动，给用户"卡入"的感觉
- **防抖**: 同一格子只触发一次，避免重复震动

#### 2. 快速跨越震动 (Fast Crossing Vibration)
- **触发条件**: 快速拖动时，方块跨越格子边界
- **震动类型**: `HapticPatterns.PresetType.LightImpact`
- **特点**: 轻度冲击震动，提供格子边界感知
- **防抖**: 50ms冷却时间，避免频繁触发

#### 3. 方块放置震动 (Placement Vibration)
- **触发条件**: 拖动结束时，方块移动到新位置
- **震动类型**: `HapticPatterns.PresetType.MediumImpact`
- **特点**: 中度冲击震动，确认操作完成
- **防抖**: 每次拖动操作只触发一次

### 消除震动系统

#### 4. 单行消除震动 (Single Line Clear)
- **触发条件**: 消除1行方块时
- **震动类型**: `HapticPatterns.PresetType.Success`
- **特点**: 成功震动，给予正面反馈

#### 5. 多行消除震动 (Multi Line Clear)
- **触发条件**: 消除2行方块时
- **震动类型**: `HapticPatterns.PresetType.LightImpact`
- **特点**: 轻度冲击震动，表示不错的成绩

#### 6. 大量消除震动 (Mass Clear)
- **触发条件**: 消除3行及以上方块时
- **震动类型**: `HapticPatterns.PresetType.MediumImpact`
- **特点**: 中度冲击震动，表示优秀成绩

#### 7. 连击消除震动 (Combo Clear)
- **触发条件**: 连击3次及以上时
- **震动类型**: `HapticPatterns.PresetType.HeavyImpact`
- **特点**: 重度冲击震动，表示卓越成绩

#### 8. 特殊方块消除震动 (Special Block Clear)
- **触发条件**: 消除特殊方块时
- **震动类型**: 根据特殊方块类型：
  - 彩虹方块：`HeavyImpact`
  - 青铜方块：`MediumImpact`
  - 金色方块：`HeavyImpact`
- **特点**: 强烈震动反馈，突出特殊方块的重要性

### 拖动震动代码结构

#### 1. 震动状态管理
```csharp
private float _lastVibrationTime = 0f;          // 上次震动时间
private const float VIBRATION_COOLDOWN = 0.05f; // 震动冷却时间（50ms）
private int _lastGridPosition = int.MaxValue;    // 上次所在格子位置
private bool _hasTriggeredPlacementVibration = false; // 放置震动标志
```

#### 2. 震动触发方法
```csharp
// 格子吸附震动
private void TriggerGridSnapVibration()
{
    if (ShouldTriggerVibration())
    {
        HapticPatterns.PlayPreset(HapticPatterns.PresetType.Selection);
        _lastVibrationTime = Time.unscaledTime;
    }
}

// 快速跨越震动
private void TriggerFastDragVibration(Vector2 currentPos)
{
    int currentGrid = Mathf.RoundToInt((currentPos.x - _originalPos.x) / Constant.BlockWidth);
    if (_lastGridPosition != int.MaxValue && _lastGridPosition != currentGrid)
    {
        if (ShouldTriggerVibration())
        {
            HapticPatterns.PlayPreset(HapticPatterns.PresetType.LightImpact);
            _lastVibrationTime = Time.unscaledTime;
        }
    }
    _lastGridPosition = currentGrid;
}

// 方块放置震动
private void TriggerPlacementVibration()
{
    if (!_hasTriggeredPlacementVibration && ShouldTriggerVibration())
    {
        HapticPatterns.PlayPreset(HapticPatterns.PresetType.MediumImpact);
        _lastVibrationTime = Time.unscaledTime;
        _hasTriggeredPlacementVibration = true;
    }
}
```

### 消除震动代码结构

#### 1. 震动状态管理
```csharp
private float _lastClearVibrationTime = 0f;          // 上次消除震动时间
private const float CLEAR_VIBRATION_COOLDOWN = 0.1f; // 消除震动冷却时间（100ms）
```

#### 2. 震动触发方法
```csharp
// 普通消除震动
private void TriggerClearVibration(int clearCount, int comboLevel = 0)
{
    if (!ShouldTriggerClearVibration()) return;
    
    HapticPatterns.PresetType vibrationType;
    if (comboLevel >= 3)
        vibrationType = HapticPatterns.PresetType.HeavyImpact;
    else if (clearCount >= 3)
        vibrationType = HapticPatterns.PresetType.MediumImpact;
    else if (clearCount >= 2)
        vibrationType = HapticPatterns.PresetType.LightImpact;
    else
        vibrationType = HapticPatterns.PresetType.Success;
    
    HapticPatterns.PlayPreset(vibrationType);
    _lastClearVibrationTime = Time.unscaledTime;
}

// 特殊方块消除震动
private void TriggerSpecialClearVibration(int specialType)
{
    if (!ShouldTriggerClearVibration()) return;
    
    HapticPatterns.PresetType vibrationType;
    switch (specialType)
    {
        case (int)Blocks.Special.Rainbow:
        case (int)Blocks.Special.Gold:
            vibrationType = HapticPatterns.PresetType.HeavyImpact;
            break;
        case (int)Blocks.Special.Bronze:
            vibrationType = HapticPatterns.PresetType.MediumImpact;
            break;
        default:
            vibrationType = HapticPatterns.PresetType.MediumImpact;
            break;
    }
    
    HapticPatterns.PlayPreset(vibrationType);
    _lastClearVibrationTime = Time.unscaledTime;
}
```

#### 3. 防抖机制
```csharp
private bool ShouldTriggerVibration()
{
    // 检查冷却时间
    if (Time.unscaledTime - _lastVibrationTime < VIBRATION_COOLDOWN)
        return false;
    
    // 检查是否在新手引导中
    if (Player.IsInGuide())
        return false;
    
    return true;
}
```

## 🎮 用户体验优化

### 震动强度分级
- **Selection**: 最轻微，适合频繁的吸附操作
- **Success**: 轻度正面反馈，适合单行消除
- **LightImpact**: 轻度冲击，适合快速跨越和双行消除
- **MediumImpact**: 中度冲击，适合方块放置和多行消除
- **HeavyImpact**: 重度冲击，适合连击和特殊方块消除

### 防抖策略
- **拖动震动**: 50ms冷却时间，避免过于频繁的震动
- **消除震动**: 100ms冷却时间，避免连续消除时的震动重叠
- **状态防抖**: 同一格子只触发一次吸附震动
- **操作防抖**: 每次拖动操作只触发一次放置震动

### 特殊情况处理
- **新手引导**: 引导期间禁用震动，避免干扰
- **石头方块**: 不可移动方块不触发震动
- **边界限制**: 在边界处不触发无效震动

## 🎯 总结

本次震动功能实现采用了**双重反馈策略**，涵盖了游戏的核心交互：

### 拖动震动系统
1. **慢速拖动**: 格子吸附震动提供精确定位反馈
2. **快速拖动**: 跨越震动提供边界感知反馈
3. **操作完成**: 放置震动提供最终确认反馈

### 消除震动系统
1. **单行消除**: 成功震动提供正面反馈
2. **多行消除**: 渐进式震动强度反映成绩优劣
3. **连击消除**: 重度震动突出卓越表现
4. **特殊消除**: 差异化震动突出特殊方块价值

通过精心设计的防抖机制、合理的震动类型选择和智能的强度分级，为用户提供了丰富、自然、直观的触觉反馈体验，显著提升了游戏的操作手感、成就感和整体沉浸感。
